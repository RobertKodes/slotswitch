# slotswitch

Live Solana mainnet as a **1940s Western Electric telephone switchboard**.

Patch cords are recent txs — tip/ring colors by program family. Lamp board blinks with the slot clock. Cord-shelf glow / busy buzz ≈ fee pressure. Dropped plugs and red supervisory lamps ≈ failed txs. Pull the night key to freeze a sample.

Not an explorer. Not a dashboard. Not a newspaper.
